# Archive

Records of work that has been completed: review rounds, remediation plans,
one-time reports, and epic planning artifacts.

Nothing here describes how the system works today, and nothing here should be
followed as guidance. A document in this directory was accurate about a moment
that has passed. Current documentation lives in [`docs/`](../docs/), starting
with the [development guide](../docs/development/README.md).

Files are kept rather than deleted because a few are still cited from issues and
pull requests. Delete one freely when nothing references it any more.
